# 居所助手 · gs_jusuo

> 早柚核心（gscore / gsuid_core）插件：王者荣耀世界「居所助手」数据查询 —— 菜地/牧场高倍收购、物品清单、行情走势，本地出图。

数据来自玩家自发分享的 [jusuo.playmmo.cn](https://jusuo.playmmo.cn)，插件直连其公开只读 Supabase 接口，不经网页渲染，单次查询通常在 200–400ms。

一套逻辑多平台通用：QQ、QQ 频道、微信、Telegram、KOOK、Discord、飞书等，只要 gscore 支持就能用。

## 功能

- **`菜地` / `牧场`**：高倍收购列表，支持按物品名筛选、单价/售价两种排序、翻页；每条带商人 UID、等级、剩余时间、整批预计售价。
- **`物品列表`**：列出两类当前在售的全部物品名（纯文本）。
- **`行情`**：近 N 小时各物品的最高成交估价峰值。
- **本地出图**：Pillow 绘制 960px 宽卡片，深蓝配色 + 大字号，不联网、约 0.2 秒一张；绘制失败自动退纯文本。
- **AI 可调用**：命令注册时带 `to_ai` 描述，接入了 AI Core 的环境可直接用自然语言触发。

## 安装

**方式一：网页控制台（推荐）**

打开 gscore 控制台 → 插件管理 → 安装插件，填入仓库地址 `https://github.com/towjf/gs_jusuo`，等待安装完成后在插件配置页确认启用。

**方式二：手动**

```bash
cd gsuid_core/plugins
git clone https://github.com/towjf/gs_jusuo.git
```

重启 gscore，日志出现 `插件gs_jusuo导入成功!` 即可。

**方式三：上传 zip**

把仓库里的 `gs_jusuo` 文件夹（内含 `__init__.py`）整体放进 `gsuid_core/plugins/` 下，目录名保持 `gs_jusuo`。

依赖只有 `httpx` 与 `Pillow`，两者 gscore 本身已自带，通常无需额外安装。

## 命令

| 命令 | 说明 |
| --- | --- |
| `菜地 [物品] [单价\|售价] [页数]` | 菜地作物高倍收购，默认售价优先、第 1 页 |
| `牧场 [物品] [单价\|售价] [页数]` | 牧场动物产物收购，规则同上 |
| `物品列表` | 菜地 + 牧场在售物品名清单 |
| `行情 [菜地\|牧场] [小时]` | 行情峰值，默认菜地、24 小时 |
| `居所帮助` | 命令一览（图片） |
| `居所状态` | 自检：接口连通性、出图方式、版本（**仅超级管理员**） |

示例：

```
菜地                    → 全部物品，售价优先第 1 页
菜地 草莓               → 只看名字含「草莓」的
菜地 草莓 单价 2         → 草莓类，按单价排序第 2 页
牧场 羊毛               → 只看羊毛类产物
行情 牧场 48            → 牧场产物近 48 小时峰值
物品列表                → 列出两类全部物品名
```

附加过滤（可选，默认不过滤）：`菜地 倍率2 等级70 售价`。

### 前缀与权限

插件**只注册裸命令**（`菜地`、`牧场`、`物品列表`、`行情`、`居所帮助`、`居所状态`），因为 gscore 的 `force_prefix` 会把每个命令按前缀展开成多份触发器 —— 填了 `居所` 之后控制台里每条命令都会出现「菜地」和「居所菜地」两条。需要前缀时，请在插件配置的 `prefix` 里自行添加（此时会同时保留裸命令，除非关掉 `allow_empty_prefix`）。

每条命令是一个独立的 SV，可以单独开关、单独设权限与优先级：

| SV | 触发词 | 默认权限 |
| --- | --- | --- |
| 居所助手-菜地 | `菜地` | 6 所有人 |
| 居所助手-牧场 | `牧场` | 6 所有人 |
| 居所助手-物品列表 | `物品列表` | 6 所有人 |
| 居所助手-行情 | `行情` | 6 所有人 |
| 居所助手-命令帮助 | `居所帮助` | 6 所有人 |
| 居所助手-自检 | `居所状态` | **1 超级管理员** |

权限等级：0 主人 / 1 超级管理员 / 2 群主 / 3 群管理员 / 6 普通用户。

## 配置

配置会写入 `gsuid_core/data/gs_jusuo/config.json`，也可在网页控制台修改。

| 键 | 说明 | 默认 |
| --- | --- | --- |
| `supabase_url` | 数据接口地址 | `https://db.playmmo.cn` |
| `anon_key` | 公开只读 key，留空用内置 | 空 |
| `timeout` | 请求超时（秒） | `15` |
| `cache_ttl` | 基础数据缓存秒数 | `90` |
| `default_sort` | 默认排序：`售价` / `单价` | `售价` |
| `page_size` | 每页条数 | `10` |
| `hide_limited` | 排除已限购条目 | `true` |
| `fetch_limit` | 单次拉取条数 | `300` |
| `use_image` | 输出图片卡片 | `true` |
| `market_hours` | 行情默认小时数 | `24` |

## 数据与隐私

- 数据全部来自 `db.playmmo.cn` 的公开只读接口（站点前端内置的 anon key，仅有 RLS 允许的读权限），插件不写入、不上传任何数据；
- 卡片在本地绘制，图片不经过任何第三方渲染服务；
- 展示的商人 UID 等信息是站点本身公开的玩家分享内容，仅供游戏内找摊位使用；
- 估价按站点公式推算：`单价 ×(1+等级加成)× 倍率 × 数量 ×(1+满贡献0.2)`，与游戏内实际成交可能存在差异。

> 站点接口由第三方维护，若对方调整字段或鉴权，插件需要同步更新。欢迎提 issue。

## 开发

```
gs_jusuo/
├── __init__.py          # Plugins + SV + 命令注册
├── jusuo_config.py      # 网页控制台配置项
├── jusuo_api.py         # Supabase REST 客户端（httpx，带缓存与重试）
├── jusuo_params.py      # 参数解析（纯函数）
├── jusuo_view.py        # 数据 → 卡片视图模型
├── jusuo_image.py       # Pillow 绘制（改配色/字号只动这里）
├── jusuo_text.py        # 纯文本兜底
├── jusuo_format.py      # 金额、时间、估价公式
└── tests/               # 单测 + 无 gscore 环境的冒烟测试
```

```bash
# 单元测试（不需要 gscore，有 Pillow 即可）
python -m unittest discover -s tests -p "test_*.py"

# 冒烟测试：用桩模块假装 gscore，真实拉数据跑全部命令
python tests/smoke_test.py
```

`tests/stub_gsuid_core/` 是给冒烟测试用的最小桩，不会被 gscore 加载。
